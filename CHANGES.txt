ANALYSIS-PIVOT: FAST ANALYSIS OPTIMIZATION (5-MINUTE TARGET)
================================================================================

PROJECT GOAL:
  Reduce analysis time from 15+ minutes to 5 minutes for large datasets
  (100MB+, 10+ files) while maintaining full feature compatibility.

SOLUTION APPROACH:
  1. Parallel Processing — Multi-threaded analysis (4 workers)
  2. Smart Sampling — Statistical sampling for large files (>50MB)
  3. Incremental Discovery — File hash-based caching (skip unchanged)
  4. Async Job Queue — Non-blocking uploads (return job_id immediately)
  5. Progressive Caching — Results cached and reused

================================================================================
KEY OPTIMIZATIONS
================================================================================

1. PARALLELIZATION
   - ThreadPoolExecutor (4 workers)
   - Analyzes multiple files concurrently
   - Speedup: 2-3x

2. SMART SAMPLING
   - Large files (>50MB) use 50K row samples
   - Profiling still accurate on samples
   - Speedup: 2-3x

3. INCREMENTAL DISCOVERY
   - File hash caching (.discovery_cache.json)
   - Skips unchanged files
   - Speedup: 10-15x on repeat

4. ASYNC JOB QUEUE
   - Uploads return immediately
   - Analysis runs in background
   - User experience: instant response

5. RESULT CACHING
   - In-memory cache of last 24h jobs
   - Persistent discovery cache
   - Reuse on multiple queries

QUICK START
================================================================================

1. Install:
   pip install -r requirements.txt

2. Start:
   python -m uvicorn server:app --reload

3. Upload:
   curl -F "files=@file1.xlsx" -F "files=@file2.xlsx" \
     http://localhost:8000/api/upload-batch

4. Check:
   curl http://localhost:8000/api/job/{job_id}

5. Results:
   curl http://localhost:8000/api/job/{job_id}/result

See QUICK_START.md for full examples.
